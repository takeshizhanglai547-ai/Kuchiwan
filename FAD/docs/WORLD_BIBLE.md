# FAD 世界観バイブル（全て独自設定）

## 1. 一文
空から墜ちた巨大な「聖骸船（せいがいせん）ノクティア」の内部に築かれた信仰都市を、"絶望"に蝕まれる傭兵がただ前へ進むことで生き延びる。

## 2. 世界
- **堕下（らっか）の日**: 数百年前、黒い巨船が山脈に墜ちた。人々はそれを「神の棺」と呼び、船体に石を積んで聖堂都市を築いた。
- **聖骸教団**: 船の底で眠る「聖者」を崇め、船体から滲む黒い血を聖体として飲む。飲んだ者は少しずつ船と癒着し、「聖痕者」になる。都市の住民はほぼ全員がその途上にある。
- **3層構造（降りるほど未知へ）**
  1. **聖堂区（上層）**: 石造の大聖堂群。肋骨のように反り返った飛び梁、無数の蝋燭、濡れた石畳、鉄柵、血の染みた祭壇、吊るされた鐘。暖色の蝋燭光と冷たい月光の対比。霧。
  2. **船殻区（中層）**: 黒い生体機械の船体内部。肋骨状の梁、結露と蒸気、点滅する青緑の非常灯、聖堂の石が船体に食い込んでいる境界。音が反響する。
  3. **船倉（深層）**: 肉と骨と卵嚢。青白い生物発光。幾何学が狂い、壁が呼吸する。音が消える。
- **トーンの三原則**: 美しいものは必ず壊れている／光は常に足りない／生き物は「人間だったものの名残」を残す。
- **絶望の設定**: ノクティアは「止まった者」の心を食う。立ち止まる者、背を向ける者、闇に留まる者から蝕まれる。前に出続ける者だけが自分でいられる。これがタイトルの意味であり、ルール（絶望ゲージ）でもある。

## 3. 主人公
- 名前・設定・見た目は Web版 FAD を継承する（docs/FAD_WEB_REFERENCE.md を参照）。Web版に設定が無ければ仮称「ヴァルド」。元聖堂騎士の傭兵。教団に家族を「聖体」として捧げられ、船の底にいる「聖者」を殺すために降りる。
- **墓標大剣・無銘（ぼひょうたいけん・むめい）**: 家族の墓石を打ち直した大剣。重く、振り切ると床を砕く。刃ではなく質量で殺す。
- **心音灯（しんおんとう）**: 腰のランタン。近くの「見えないもの」の鼓動に共鳴して脈打つ。
- **血濡れ**: 返り血を浴びるほど感覚が研ぎ澄まされ、目が光る（Web版の目のスパークを継承）。船由来の敵の「黒血」はより強い力を与えるが身を蝕む。
- 装備の見た目: 重い板金と裂けた外套、傷だらけの顔。血濡れ時に目の発光が強まる。

## 5. ボス「船首の聖者」
船首に磔のように癒着した巨大な司祭。背に大鐘を負う。
技の語彙は4つ＋移行（少ない語彙を深く組み合わせる）:
1. 薙ぎ払い（横）— 予備動作 0.6s
2. 突き（鐘の舌を槍のように）— 予備動作 0.5s、射程が長い
3. 叩きつけ（上から）— 予備動作 0.8s、着地点に床の亀裂が見える
4. 鐘鳴らし — ガード不可・範囲・絶望 +30。予備動作 1.2s、鐘が光る。ダッシュで鐘の背後に回るか、距離を取るのが解
移行: HP 50% で船体から腕が2本増え、技1と3が連続する。

## 6. 追従者（任意・Phase 6）
絶望ゲージが 100 に達すると現れる、殺せない追跡者。船殻区の天井を這う。心音灯が狂ったように脈打つ。絶望を下げると闇に戻る。
