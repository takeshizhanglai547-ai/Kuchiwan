# FAD ゲームデザイン仕様（UE5 2.5D 版）

## 1. コアループと原則
前進 → 遭遇（予備動作を見て判断）→ 攻撃で返り血が溜まり絶望が減る → 区画クリアで祝福／呪いの3択 → 休憩所 → ボス。
- **守りが攻めに勝ってはいけない**: 安全策はゼロリターン、リスクを取る者にリターン。
- **小さな語彙・深い組み合わせ**: 敵の技は少なく、組み合わせで複雑にする。
- **手触り最優先**: 判断は常に「重い一撃の感触」「痛みの直接性」を基準に。
- **理不尽ゼロ**: 全ての攻撃に 0.4s 以上の予備動作（発光＋構え＋音）。反応すれば避けられる。

## 2. 2.5D の定義とカメラ
- 移動は X-Z 平面、Y = 0 固定。向きは左右のみ（振り向き 0.08s）。
- カメラ: SpringArm、やや下向き（ピッチ -8°）、FOV 40、距離 900、プレイヤー先行オフセット 150（向いている方向）、目線 +90、追従デッドゾーン。
- 区画ごとに**カメラレール**（Spline）で角度・FOV・距離を変える。巨大な空間に入る時は**リビールボリューム**で 2〜3 秒の"引き"の画を見せる。
- 被写界深度: 前景（手前の柱・鎖）を軽くボカす。背景は奥行き 30〜100m を作り込む（遠景のシルエット、動くもの）。
- 奥行きレーン移動は今回は無し（Phase 6 以降の候補）。

## 4. ゲージ（全て UI に出す）
| ゲージ | 増える | 減る／効果 |
|---|---|---|
| HP | 回復は祝福・休憩所・前進回復のみ | 0 で死亡 |
| 返り血（Web版継承） | ヒット・撃破（黒血持ちは 1.5 倍） | 最大で**血濡れ**: 速度 1.3 倍・目のスパーク・持続後に減衰（Web版の値） |
| テンペスト（Web版継承） | Web版と同じ条件 | Web版と同じ大技。発動中はスロー＋カメラ寄り |
| **絶望（新）** | 暗闇（心音灯の範囲外）+2/s、後退 +3/s、2秒以上の停止 +1/s、被弾 +10、鐘鳴らし +30 | 攻撃ヒット -3、撃破 -10、トドメ -20、前進ダッシュ -1。**100 で「絶望の淵」**: 回復不可・画面が暗く耳鳴り・敵攻撃力 +30%（Phase 6 で追従者）。70 未満に戻すと解除 |
| 前進回復（新） | 被弾後 2.5s 以内に攻撃ヒット | 失った HP の 50% を回復（守るより殴る方が得になる仕組み） |
| 腐食（黒血のデバフ） | 黒血持ちへのヒット | 防御 -20% を 5s。返り血は多く溜まる（リスクと報酬） |

## 5. 敵共通ルール
- 全攻撃に予備動作 ≥ 0.4s。予備動作は「発光（Niagara）＋構えポーズ＋固有の音」の3点セット。
- ヒット反応 3 種（小怯み／大怯み／打ち上げ）。鉄化エリートは一定ダメージまで怯まない。
- 死亡時: 血しぶき（Niagara）＋床・壁の血デカール（同時上限 64、古い順にフェード）＋ラグドール（2〜3 秒後に消える）。
- 撃破・トドメ・エリート撃破でスロー演出（Web版継承）。

## 6. エリートと AI ディレクター
- エリートはコンポーネントで付与（1体に最大2種）。出現率は区画の深さと天候で変わる（血の月で「渇き」が出やすい）。
- ディレクター: 緊張度 = f(残 HP, 直近 30s の殲滅速度, 絶望ゲージ)。高いと出現数と編成を抑え、低いと増やす。大群の後に必ず静かな区間を挟む。数値はログに出す。

## 7. 区画と連結ルール（Web版継承 → Level Instance で実装）
通路／アリーナ（左右封鎖、全滅で解除）／罠回廊／伏兵（背後からも出現）／宝部屋／休憩所。
- アリーナを2連続にしない。ボス区画は最後に固定、その直前は休憩所。
- どの組み合わせでも必ずクリア可能（飛び越えられない穴、登れない段差を作らない）。
- シード値をポーズとリザルトに表示。トレーニングモードは固定。
- 各区画はドア用ソケットで X 方向に連結する。100 シードの自動テストで連結ルールを検証。

## 8. 天候（Web版継承）
夕暮れ／豪雨／霧／血の月。ライティングとポストプロセスのプリセットを切り替え、敵の性質に連動（血の月 → 渇きエリート増）。

## 9. 祝福／呪い（Web版の全リストを継承し、必要なら追加）
アリーナクリアごとにランダム 3 つから 1 つ。例: 血の渇望（返り血 1.5 倍）／双嵐（テンペスト 2 連発）／死線（HP 30% 以下で攻撃 2 倍）／狂犬の牙（コンボ数で攻撃上昇）／呪われた刃（攻撃 +40%・被ダメ +25%）。新規候補: 墓守の誓い（絶望の増加 -50%、回復 -30%）／黒い聖体（黒血の腐食を無効、返り血 1.2 倍）。
HUD とポーズに小さく表示。コンティニューで維持、新規開始でリセット。

## 10. UI・モード
- HUD: HP／返り血／テンペスト／絶望／祝福アイコン。数字のダメージ表示は出さない（リアル調）。
- 字幕: 日本語（Web版継承）。フォントは Noto Sans JP（OFL ライセンス）。
- 画面: タイトル／ポーズ／リザルト（シード表示）／ゲームオーバー（コンティニュー）。
- トレーニングモード: 固定区画、全コマンド表示、ダミー。
- セーブ: 休憩所で自動。設計は着手前に報告（CLAUDE.md ルール 5）。

## 11. 継承マップ（Web版 → UE5）
| Web版 | UE5 での実装 |

| 松明の光・霧・火の粉 | Lumen／MegaLights、Volumetric Fog、Niagara（灰・胞子・火の粉） |
| 血痕 | デカール（Decal Actor、上限管理） |
| 敵データ表 | DT_Enemies（DataTable） |
| 祝福リスト | DT_Blessings |

| 天候 | PostProcess／ライティングのプリセット切替（DataAsset） |
| タッチ操作 | ゲームパッド＋キーボード（PC 版のため不要） |
| BGM/SE | MetaSounds。Web版の曲はライセンス確認後に再利用 |
