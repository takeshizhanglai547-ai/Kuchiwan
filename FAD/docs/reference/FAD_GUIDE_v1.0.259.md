## 1. 物語（STORY）

### 1-1. 世界設定

- **舞台**
  - 聖血と鐘の街「ヴェスグレイヴ」が舞台です。
  - 教会は夜ごとに鐘を鳴らし、あらゆる病を癒す聖血を人々に分け与えていました。
- **発端**
  - ある夜から鐘が鳴りやまなくなり、三日三晩鳴り続けたあと、四日目の朝に止まりました。
  - それ以来、門をくぐった者は誰も戻りません。
- **主人公**
  - かつて教会に狩られ、地の底へ捨てられた者です。
  - 失った左腕に、出所の知れない鉄の義手（義手大砲）を付けています。その奥で、何かが鐘に合わせて脈打ちます。
  - 「夜明けは来ない。ならば、夜を斬り拓くまで。」
- **構成の方針**
  - 語り口は文字ではなく、配置と演出で物語を語る方式です。手本はブラッドボーン型です。
  - ゴシックホラーから始まり、やがて星からの来訪者・上位者との戦いへ移ります。
- **語りの場面**
  - 「仮想カード」（id 1000以上）を使って、次の場面で語りが入ります：オープニング、各面の開始、各面のクリア（成績のあと、ワールドマップの前）、夜（踏破数3／6／9）、結末。
  - 1ページの表示時間は最大24秒です（4.5秒＋1行1.7秒＋3秒）。攻撃ボタンで送れます。
- **配置で語る演出**
  - 各面の始まりにその面ならではの出来事があり、ボスの手前には先に挑んで倒れた騎士たちの骸が横たわっています（README:28（項目6）, 63-66（項目29）、）。
  - 雑魚の登場の仕方は次の7種類です。
    - 1 奥から跳び込む
    - 2 地面からせり上がる
    - 3/6 飛行型に運ばれて落とされる
    - 4/5 騎乗して来る
    - 7 上から落下する
    - 8 空中から揺らめいて現れる
  - 各面の開幕は、それぞれ決まった登場の仕方で始まります。面Ⅰ〜Ⅹの順に 1,3,2,2,7,2,4,2,1,2 です。

## 2. 面と進行（STAGES）

### 2-1. 全体の構造

- **進み方**
  - 面をクリアするとワールドマップが開きます。まだ踏破していない地のどれか、または「血の闘技場」を選べます（、、README:130（項目59））。
  - 全ての地を踏破すると物語が終わります。
- **ワールドマップ**
  - 危険度は★で表示されます。Ⅰ〜Ⅹは「面番号÷2＋1」個（切り捨て）、Ⅺ以降は★6です。
  - 地図の下に、その地の名前・危険度・ひとこと（Omen）が出ます。
- **面選択**
  - タイトルの面選択からどの面でも遊べます。ただし、ここで選んだ面はクリア記録に残りません。
- **解放条件**
  - Ⅺ：Ⅰ〜Ⅹをすべてクリアすると、面選択の一番下に出ます（README:40（項目11））。
  - Ⅻ〜ⅩⅣ：Ⅺの先へ続きます。面選択からも選べます（README:180（項目78））。
  - ⅩⅤ：ワールドマップ左下の沼地から選べます（README:234（項目109））。
- **面の中の構成**
  - 遭遇の流れは「開幕の波 → 中ボス → 混成の波 → ボス」が基本です。
  - ボスは「遭遇枠3」の位置で現れます。
  - ステージの並び・天候・祝福／呪いは、遊ぶたびに変わります。
- **隠し部屋（裏世界）**
  - Ⅰ〜Ⅹの各面に、上層の塔と地下墓所の2部屋があります。
  - 部屋は長い3広間で構成され、広間に入ると閉じ込められます。最後の広間に番人がいます。
  - 錆とコンクリートに血管が脈打つ「裏の世界」で、入るとサイレンが鳴ります（、README:241（項目111））。
- **探索型マップ**
  - ⅩⅤ以外の全ての面が、扉でつながる部屋を持つ探索型です（README:409（項目266））。
  - 鍵の部屋の遺物（鍵）を取るまで、ボスの手前の道は閉ざされています。
  - ⅩⅤは独自の屋敷マップで、鍵は屋根裏の祭壇にあります。
- **地形の物語**
  - Ⅳ・Ⅶ・Ⅷ・Ⅹ・Ⅻ・ⅩⅣは、地面の高さが物語に沿って作られています（、README:384（項目241））。
  - 細かい起伏のランダム化は廃止されました。敵の出方は毎回変わります。
- **場面の小物**
  - 死体や小物は、面ごとに3〜4の「場面」にまとめて置かれています。

## 4. ボス（BOSSES）

### 4-0. 共通の前提

- **回避の無敵**
  - 回避すると0.44秒無敵になります。ジャスト回避なら0.58秒です。
  - HurtPlayer を通る攻撃は、無敵中はすべて当たりません。
  - 例外：体力を直接減らす攻撃は無敵でも防げません。チェーンソーの押し付け、ジャックの握り潰し、捕食中の噛みつき、絡みつきがこれに当たります。
- **防御の判定順**
  - 無敵中
  - ガード崩しの掴み
  - 押しっぱなしの連続弾き
  - パリィ
  - 通常ガード
  - ガード不能フラグの付いた攻撃は、ここまでの防御をすり抜ける
- **ハザード（設置型の攻撃）の判定**

| 種類 | 発動と判定 | 避け方 |
|---|---|---|
| ビーム | 予告線0.65秒のあと、床から斜め上へ掃く | ジャンプ／回避／弾き |
| 吐瀉物の塊 | 0.55秒後に着弾。範囲 \ | dx\ | 着弾点から離れる／回避 |  |
| 落雷 | 0.40秒後。範囲 \ | dx\ | ジャンプでは避けられない。横へ動くか回避 | — |
| 火柱 | 0.55秒予告のあと発生。範囲 \ | dx\ | 横へ避ける／回避 |  |

### 4-2. 全ボス共通の仕組み

- **被ダメージ倍率**。次の倍率が掛け算で重なります。
  - ボス・中ボス・巨人本体の攻撃：×1.25
  - 全敵：×1.35（候補206）、さらに×1.25（候補216）
  - 怒ったボスの近く（260以内）：×1.25
  - ボス戦中：×1.3
  - レベル補正：×(1＋0.022×(Lv−1))
  - 合計すると、ボス本体の打撃はボス戦で約2.74倍、怒り中は約3.43倍です（レベル補正は別）。README の「約1.25倍」、「1.3倍」は、このうち一段分だけを説明したものです。
  - 巨人の全身攻撃は、倍率に関係なく最大HPの1/3を固定で奪います。
- **怒りと第二形態**
  - 体力50%以下が0.35秒続くと発動します。
  - 時間が止まり、700以内にいる主人公は吹き飛ばされます（0.8秒無敵）。BGM にラテン語風の詠唱が重なります。
  - 以後、ボスは1.3倍速になり、攻撃は1.25倍になります。
  - 次の一覧のボスは姿が変わります：5, 12, 26, 42, 52, 59, 65, 108, 112, 116, 121, 122, 123。変身中の1.6秒は攻撃が通りません。
  - 第二形態の技は、3.6〜5.6秒ごとに出ます。
  - 「赤いオーラ」と「怒った表示」は候補217で廃止されました（README:223（項目102））。
- **スーパーアーマー**（、README:208（項目94））
  - 中ボスと大ボスは、攻撃中は怯みません。
  - 大ボスは弱攻撃では常に怯みません。重い一撃を3回（怒り中は4回）当てるごとに怯みます。中ボスは2回ごとです。
- **種族共通の大技（Big216）**
  - **飛びかかりの投げ**：0.55秒赤く光って屈み、跳びかかってきます。着地点にいると掴まれ、3回噛まれてから最大HPの16%で投げられます。
    - 避け方：着地点の印から離れる、着地の瞬間に回避する、または高さ130以上にいる。
  - **大振り（ヘイメイカー）**：1.25秒溜めてから秒速1600で踏み込みます（最大HPの26%）。Hammer／Bash／Hook 型が、距離520未満のときに使います。
    - 避け方：回避するか、溜めの間に背後へ回る。
  - **目からのビーム**：候補226以降、レギオン型のボスだけが使います。
  - README 項目94 の「大爆発」の処理は、候補217以降は実行されません（要確認）。
  - 固有技（Sig253）を持つ面ボスは Big216 を使いません。
- **火柱・落雷パターン（候補222）**（、README:270（項目127））
  - 種類：火柱の行進（本体から外へ6本）、火柱の檻（足元に1本→±330・±660）、落雷の嵐（5本＋0.75秒後に3本）、火柱の輪（左右へ広がる）。
  - 予告は0.45秒の震えです。火柱は柱そのものに触れたときだけ当たります（\|dx\|<170）。横へ避けます。
  - 固有技を持つボスは使いません。実際に使うのはゾイ、ジャック、最後の落とし子などです。
- **ボス戦前から再開**：倒れても、ボス戦の直前から立ち上がれます。表示は「Enter／Options：ボスの前から立ち上がる」です。
- **ボスの攻撃はすべて吹き飛ばす**：ラッシュ中のボスは怯みません（README:46（項目15）、NukoBoss187.cpp）。
- **止めの演出**（、README:212（項目95））
  - ボス・中ボスを倒した瞬間と処刑の最後の一撃で、時間がほぼ止まります。画面が寄って黒帯が入り、白い斬撃が走ります（メタルギアライジング風）。
  - 止めの効果音は「ズドーン！！」です（README:179（項目77））。
- **掴み・投げからは抜けられない**（候補221。、README:265（項目122））
  - 対象は Boss、Elite、ステージボス、ゾイ、ジャックです。連打も義手大砲も効きません。
  - 例外は4つです。
    - ゾイのチェーンソー：12回連打で振りほどける
    - 悪夢の肉塊の捕食：連打か義手大砲で抜けられる
    - 肉片の絡みつき：連打で振りほどける
    - 固有技の罠（4-1の「捕まる技」）：連打で早く抜けられる

  - 候補125：ガードを0.35秒以上固め、330以内で接地していると、0.42秒「GRAB!」と予告してから掴まれます。避けるには回避かジャンプです。

  - ボスごとの登場の仕方：Ⅰ〜ⅩⅤの順に、落下／跳躍／せり上がり／巨像／揺らめき／落下／跳躍／せり上がり／巨像／なし／揺らめき／せり上がり／落下／巨像／落下。
