# BERSERK 黒い剣士 ─蝕の夜─

カプコンのアーケード『エイリアンVSプレデター』(1994) のベルトスクロールアクションを手本に、
キャラクターと世界観を『ベルセルク』に置き換えた **非公式ファンメイド** のブラウザゲームです。
画像・音声ファイルは一切使わず、キャラクターも背景も BGM もすべてプログラムで生成しています。

## 遊び方

| 方法 | 手順 |
|---|---|
| スマホ（いちばん簡単） | 共有された claude.ai のリンクをスマホで開き、**横向き**にして画面をタップ |
| スマホ（自分で公開） | リポジトリ直下の `berserk_standalone.html`（1ファイル完結）を Netlify Drop / GitHub Pages 等に置いて開く |
| PC | `berserk/index.html` または `berserk_standalone.html` をブラウザで開く |

iPhone はマナーモード（消音スイッチ）だと音が出ません。

## 操作

**スマホ**（画面左半分がスティック、右に 5 つのボタン）

| 操作 | 内容 |
|---|---|
| 左半分をドラッグ | 移動（奥・手前にも動ける）。同じ方向に 2 回倒す、または倒しっぱなしでダッシュ |
| 斬 | 攻撃。当て続けると 4 段コンボ。**長押し→離す** で溜め攻撃 |
| 跳 | ジャンプ。空中で斬＝ジャンプ攻撃、下＋斬＝落下突き |
| 射 | 射撃（ゲージ制）。拾った武器を持っていればそちらを使う |
| 必 | 必殺技。体力を少し消費して無敵の範囲攻撃（斬＋跳の同時押しでも可。のけぞり中にも出せる） |
| 狂 | 覚醒ゲージ（HUD の「狂」）が満タンのとき光る。キャラ固有の覚醒 |
| 下→上＋斬 | 昇り斬り（対空・打ち上げ） |
| 敵に向かって歩き続ける | 掴み → 斬で膝蹴り、方向＋斬で投げ（投げた敵で他の敵を巻き込める） |
| 悪霊に張り付かれたら | ボタン連打・スティックをぐりぐり回して振りほどく |

**キーボード**: 矢印/WASD 移動、Z 攻撃、X/Space ジャンプ、C 射撃、V 必殺、B 覚醒、Shift 押しながらでダッシュ、Enter/Esc ポーズ、M 音 ON/OFF
**ゲームパッド**: 標準配置（X 攻撃・A ジャンプ・B 射撃・Y 必殺・RB 覚醒・START ポーズ）

## キャラクター

| キャラ | タイプ | 射撃 | 覚醒 |
|---|---|---|---|
| ガッツ（黒い剣士） | パワー・最長リーチ | 連射式ボウガン（長押しで義手の大砲） | 狂戦士の甲冑 |
| キャスカ（鷹の団 千人長） | スピード・空中コンボ | 投げナイフ（撃ち切るとリロード中は無防備） | 鷹の舞 |
| 髑髏の騎士（使徒を狩る者） | 重装・最大体力 | 光刃（貫通） | 空間切断（画面全体攻撃） |
| シールケ（魔女の弟子） | 魔法・射撃特化 | 精霊の火（追尾） | 四大精霊召喚（画面全体攻撃） |

## ラウンド

1. 黒い剣士 ─ 紅い月の城下町（ボス: 蛇男爵）
2. 伯爵の地下牢 ─ 地下牢と下水路（ボス: 伯爵）
3. 疾駆 ─ 馬車で森を逃走・強制スクロール（ボス: 不死のゾッド）
4. 霧の森（ボス: ロシーヌ）
5. 断罪の塔（ボス: モズグス）
6. 蝕（ボス: フェムト）

## 開発者向け

設計の約束事は [DESIGN.md](DESIGN.md)。テスト:

```
NODE_PATH=/opt/node22/lib/node_modules node berserk/tools/smoke.cjs --hero=guts --stage=0 --seconds=60 --turbo=4
node berserk/tools/build.cjs          # berserk_standalone.html を再生成
```
