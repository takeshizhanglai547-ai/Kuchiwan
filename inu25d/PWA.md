# 9ステージ拡張候補のPWA

公開復元版914を保存した別候補です。元040cfのゆったりしたキャラ別移動速度と上下レーンを基準に、コマンド技・つかみ・1台2人協力を統合しています。別端末オンライン527は含みません。App Storeのネイティブアプリではありません。

## ゲーム内容

- 全7キャラの地上/空中コマンド、つかみと方向別の派生、必殺・奥義を別ボタンに保持。
- 足・腰・胴体のroot追従を修正し、コマンドの軌跡を実動作時間に同期。
- 狙いイヌ、スカイアーマー、戦国3兵種と鬼3兵種を追加。
- 戦国和風・鬼合戦を追加した全9面。元の面番号と解放セーブを保持。
- 面ごと・ボス・後半戦・大帝3形態に対応したオリジナルの音楽。
- 半HPカットインと外観/攻撃の変化、大帝2回の形態変化カットシーン。

`inu25d/app/` と `game.html?app=1`、manifest/start_url/scope、元のアイコン・URLを維持します。通常HTMLと同じゲーム本体にアプリの保存/更新UIだけを加えます。ゲームコード内に秘密情報・外部リアルタイムサービスはありません。

## 再現

```
node tools/published-fighter.cjs
node tools/resume25d-inventory.cjs
node tools/build25d.js --offline
node tools/build25d-pwa.cjs
node tools/test25d-cpu.cjs
node tests/25d/pwa_cpu.cjs
node tests/25d/pwa_ui_cpu.cjs
node tests/25d/pwa_build_variant.cjs
```

キャッシュはビルド内容からハッシュで区別し、全10アセットを検証してから切り替えます。このアプリscopeの古い保存だけを削除し、他ゲームの保存は消しません。新版本体のタイトル/入口では安全に切替、戦闘中は強制再読込しません。既存ホーム画面で古い版が出る場合は、オンラインでタイトルの「アプリ」→「更新を確認」から切り替えるか、全画面を閉じて開き直します。オフラインだけの端末には新しい配信を送れません。`inu25d_save` の削除や互換性を壊す移行は行いません。

検証の仕様台帳は `EXPANSION_ACCEPTANCE_20261026.md` を参照してください。CPU/合成DOM/実THREEのソフトウェア描画を、WebGL・iPad実機・信頼されたタッチや音の試聴合格と混同しません。実機での見え方・操作感・音質・体感難易度の受入は未実施です。
