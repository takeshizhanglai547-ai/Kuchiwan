- 計画書は既存 FAD を「Web版（HTML/JS）」と呼んでいる。しかし過去の Claude Code Remote Control セッションの記録（2026-11-02 まで）によれば、実体はユーザーの PC 上の **Unreal Engine 5.7 C++ プロジェクト**である。
  - プロジェクトルート: `C:\UnrealProjects\ForwardClaude`（Claude Code 版。Codex 由来の旧ツリー `C:\Users\takes\Documents\Codex\...` とは別系統）
  - uproject: `Project\InnuUnreal.uproject`。ソース: `Project\Source\`（例: NukoCmd260.cpp、NukoDraw129.cpp、InnuHUD.cpp）。データ例: `Project\Story129\commands_ja260.json`
  - UE 本体: `C:\Program Files\Epic Games\UE_5.7`
  - 最新: 候補260（Ver 1.0.260、2026-11-02、Shipping ビルド、`Share\ForwardAgainstDespair-260.zip` 約 12.15 GB）。ローカル git リポジトリ（リモート URL は記録に無い）。入口文書は `CLAUDE.md`・`STATUS_JA.md`・`RESUME.md`。
- このクラウド環境からは上記 PC に触れないため、**ソースコードは読んでいない**。
- 本書の出典は、ユーザー自身の公開アーティファクト「狂戦士 攻略読本」Ver 1.0.259（https://claude.ai/artifact/9mA1J3j3bnLGdtxc67RShV）である。攻略本は PC 上の `Work259\guide\build.cjs` が「ゲームのコードと README」から生成した二次資料で、一部に候補260の記述を含む。

- 本書の数値は「攻略本に書かれている値」であり、コードの値ではない。発生・持続・硬直・ヒットストップなど攻略本に無い値は、PC 側の Claude Code が `Project\Source` を**読み取り専用**で解析して補う（手順は FAD/README.md）。既存プロジェクトの編集・移動・削除は禁止（CLAUDE.md ルール 7）。
