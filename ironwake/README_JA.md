# IRONWAKE（アイアンウェイク）— 遊び方ガイド

> English version: [README.md](README.md)

## どんなゲーム？

ブラウザで遊べる、巨大ロボット（作中では「リグ」と呼びます）のアクションゲームです。あなたは傭兵「ウェイク01」として、全高約10メートルの強襲リグ「RIG-07 アイアンウェイク」に乗り込みます。舞台は、灰が降る夕暮れの廃製鉄港「ハルヴァルド深層鋳造港・第7埠頭」。一瞬で横に跳ぶ「クイックブースト」を使って敵の攻撃をかわし、ライフル・ミサイル・キャノン・ブレードで警備部隊を倒していきます。ステージは1つで、最後にライバル機「シンダーハウンド」との一騎打ちが待っています。1回の出撃は5〜15分ほどです。

---

## はじめかた

1. `dist` フォルダの中にある **`ironwake.html` をダブルクリック**します。
   - **Google Chrome** か **Microsoft Edge** で開いてください（どちらも最新版を推奨）。
   - 別のブラウザが開いてしまったときは、ファイルを右クリック →「プログラムから開く」→ Chrome または Edge を選びます。
   - ファイルが zip に入っている場合は、先に zip を「すべて展開」してから開いてください。
2. 「LOADING / 読み込み中…」の表示のあと、タイトル画面が出ます（10〜30秒ほどかかることがあります）。
3. **START MISSION（出撃準備）** → 作戦概要を読んで → **LAUNCH（出撃）** を押すとゲーム開始です。
4. ゲーム画面を **1回クリック** すると、マウスで視点を動かせるようになります（マウスの矢印は消えます）。
   **Esc キー** で一時停止になり、マウスの矢印が戻ります。
5. **音は、最初にクリックかキーを押したあとに鳴り始めます**（ブラウザの決まりです）。

> **快適に遊ぶには、グラフィックボード（GPU）を積んだパソコンが必要です。**
> ゲーミングPCや最近のノートPCなら問題ありません。GPUのない古いパソコンでも動きますが、自動で画質と解像度が下がり、動きがかなり重くなります。

## 操作方法

### キーボード ＋ マウス

| キー / ボタン | できること |
|---|---|
| **W A S D** | 移動 |
| **マウス** | 照準（視点）を動かす。矢印キー ← → ↑ ↓ でも動かせます |
| **左クリック**（押しっぱなし） | 右腕のライフルを撃つ |
| **右クリック** | 左腕のパルスブレード（近接攻撃。ロックした敵に向かって突進して斬る） |
| **Q** | 左肩のミサイル（照準枠の中の敵を自動でロックして発射） |
| **E** | 右肩のヘビーキャノン（強力な一発。爆風あり） |
| **Shift** | **クイックブースト**（押した瞬間、移動キーの方向へ一気に跳ぶ） |
| **Space** | ジャンプ。**長押しでホバー**（空中で上昇・滞空） |
| **F** | アサルトブースト（ためてから高速飛行。もう一度 F で止まる） |
| **C** | 地上ブーストの ON / OFF（ふだんは ON。OFF にすると歩きになります） |
| **Tab** または **マウスホイールのクリック** | ロックする敵を切り替える |
| **V** | ターゲットアシスト（ロック中の敵を自動でカメラが追いかける）の ON / OFF |
| **R** | 修復キットを使う（耐久値を回復。3個まで） |
| **Esc** または **P** | 一時停止（ポーズ） |
| **Enter** | メニューで決定 |

### 画面の見かた

| 表示 | 意味 |
|---|---|
| **AP** | 機体の耐久値。0 になると撃破されて作戦失敗 |
| **EN**（エネルギー） | ブースト用の燃料。クイックブースト・ホバー・アサルトブーストで減り、使わなければすぐ回復 |
| **STAGGER / 姿勢** | 自分の体勢ゲージ。攻撃を受け続けて満タンになると、一瞬動けなくなる |
| 左上 **OBJECTIVE / 作戦目標** | 今やるべきこと、残り数、経過時間（制限 15:00） |
| 画面下の字幕 | オペレーター「レジャー」からの無線 |

## 作戦目標

ステージは3つの段階（フェーズ）に分かれています。順番にクリアしてください。

1. **ピケット部隊を撃破せよ** — 5機の警備歩行機「PK-2 ピケット」を倒す（小型無人機「ナット」も飛んできます）。
2. **中継ジェネレーターを破壊せよ** — 奥の岸壁に立つ3基の塔を壊す。塔は撃ち返してくるうえ、無人機を呼びます。
3. **敵リグ「シンダーハウンド」を撃破せよ** — 空から降りてくるライバル機との一騎打ち。

- 3つすべて終えると **MISSION COMPLETE（作戦完了）**。
- **AP が 0 になる** か、**15分を過ぎる** と **MISSION FAILED（作戦失敗）**。
- 最後に **ランク（S・A・B・C・D）** が出ます。決まり方は次の3つの合計点（100点満点）です。
  - **クリア時間**（40点）: 5分以内なら満点。遅いほど減り、15分で0点。
  - **受けたダメージ**（40点）: ノーダメージなら満点。多いほど減ります。
  - **修復キットの使用数**（20点）: 1個使うごとに 7点減ります。
  - 85点以上で S、70点以上で A、55点以上で B、40点以上で C、それ未満は D。
- 結果画面の **RETRY（再出撃）** ですぐ再挑戦、**RETURN TO TITLE（タイトルへ）** でタイトルに戻ります。
- ポーズ画面（Esc）からも **RESTART（再出撃）** でやり直せます。

## 上達のコツ

- **クイックブースト（Shift）が命です。** 移動キーと一緒に押すと、その方向へ一瞬で約40メートル跳びます。
  敵は撃つ直前に **赤い（ナットは青い）レーザー照準と光** で合図を出すので、それが見えたら横へクイックブースト。
  - 1回で EN を 17% 使います。満タンから続けて6回ほど使えます。
  - EN を使い切ると **バーが赤くなり、約2秒間ブーストが使えなくなります**。少し残しておくのが安全です。
- **ふだんは地上ブースト（C で ON/OFF）で走り回りましょう。** 地上の高速移動は EN を使いません。
- **高い所へは Space 長押しのホバー**、**遠くへはアサルトブースト（F）** が便利です。どちらも EN を使います。
- **敵の体勢を崩す（STAGGER）:** 攻撃を当て続けると敵の「姿勢ゲージ」がたまり、満タンで敵がよろめいて動けなくなります。
  このすきに当てた攻撃は **ダメージが約1.85倍**。よろめいたらすぐ **キャノン（E）** か **ブレード（右クリック）** を叩き込みましょう。
  ミサイルとキャノンは姿勢ゲージをたくさんためます。
- **ミサイル（Q）は敵を照準枠に入れておくだけで最大4体までロック** されます。角の表示が琥珀色になったら撃ちどき。
- **修復キット（R）は3個。** 1個で最大耐久値の約4割を回復します。ただし使うほどランクの点数が下がるので、AP が3割を切ったら、が目安です。
- **弾は補給できません。** ライフル540発、ミサイル120発、キャノン24発。キャノンは「よろめいた敵」に取っておくのがおすすめ。
- **ボス「シンダーハウンド」攻略:**
  - 大きな攻撃の前には必ず **光と警告音（だんだん速くなるピピピ音）** の合図があります。合図を見たらクイックブーストでかわし、その直後のすきに反撃。
  - 爆発に強い装甲なので、**ミサイルとキャノンは効きにくく、ライフルとブレードがよく効きます**（ただし体勢を崩すにはミサイル・キャノンも有効）。
  - 耐久値が半分を切ると **リミッター解除** で動きが速く、攻撃が激しくなります。

## 画質などの設定

タイトル画面またはポーズ画面の **OPTIONS（設定）** で変えられます。設定はそのパソコンのブラウザに保存されます。

| 項目 | 内容 |
|---|---|
| **GRAPHICS QUALITY（画質）** | **LOW / MEDIUM / HIGH**。動きが重いときは LOW にしてください。HIGH は光の筋やモーションブラーなどが加わります |
| LOOK SENSITIVITY（視点感度） | マウスと右スティックの視点の速さ（標準 1.0） |
| INVERT LOOK Y（上下反転） | 視点の上下操作を逆にする |
| 音量（全体・音楽・効果音・音声） | それぞれ調整できます |
| SUBTITLES（字幕） | 無線字幕の表示とサイズ |
| CAMERA SHAKE（カメラの揺れ） | 被弾や着地での揺れの強さ |
| HUD OPACITY（HUD 透明度） | 画面表示の濃さ |

**上級者向け:** ブラウザのアドレス欄で、ファイル名のうしろに `?quality=low`（または `medium` / `high`）を付けて Enter を押しても画質を指定できます。
例: `file:///C:/Users/あなたの名前/Downloads/ironwake/dist/ironwake.html?quality=low`

## 困ったときは

### 画面が真っ黒のまま / 「LOADING」から進まない
- 30秒ほど待ってみてください。初回はパソコンによって時間がかかります。
- **最新の Chrome か Edge** で開いているか確認してください。
  古いブラウザでは「このブラウザでは起動できません」と表示されます。
- 「ファイルが壊れています」と出たら、ファイルをもう一度ダウンロードしてください。
- 「WebGL2 に対応していません」と出たら、ブラウザの **グラフィック アクセラレーション** を ON にします。
  - Chrome: 右上の「︙」→ 設定 → システム →「グラフィック アクセラレーションが使用可能な場合は使用する」を ON → ブラウザを再起動。
  - Edge: 右上の「…」→ 設定 → システムとパフォーマンス →「使用可能な場合はグラフィックス アクセラレーションを使用する」を ON → 再起動。
- zip のまま開いていないか確認し、展開してから開いてください。

### 動きがカクカクする（重い）
- **OPTIONS → GRAPHICS QUALITY を LOW** にしてください。
- ほかのアプリやブラウザのタブを閉じてください。
- ノートパソコンは **電源アダプターをつないで** 遊んでください。
- GPU を2つ持つノートパソコンは、Windows の「設定 → システム → ディスプレイ → グラフィック」で Chrome / Edge を **「高パフォーマンス」** にすると速くなることがあります。
- GPU のないパソコンでは、ゲームが自動で画質と解像度を下げます。それでも重い場合は、GPU のあるパソコンで遊んでください。

### 音が出ない
- 一度画面を **クリック** するか、どれかのキーを押してください（ブラウザは操作があるまで音を出しません）。
- OPTIONS の音量、パソコンの音量、ブラウザのタブがミュートになっていないかを確認してください。

### マウスで視点が動かない / マウスの矢印が消えた
- ゲーム中に画面を **クリック** すると、マウスがゲームに固定されて視点を動かせるようになります（このとき矢印は消えます）。
- **Esc** を押すと固定が外れ、一時停止になって矢印が戻ります。続けるにはポーズ画面で **RESUME（再開）** を選び、画面をもう一度クリック。
- マウスが固定されていないときは、画面の下に **「CLICK TO AIM / クリックで照準操作」** と表示されます。画面を1回クリックすると固定されます。
- ブラウザがマウスの固定を許可しない環境では、自動的に **「ボタンを押しながらマウスを動かすと視点が回る」** 操作に切り替わり、画面の下に **「DRAG TO AIM / ドラッグで照準操作」** と表示されます。矢印キーでも視点を動かせます。
- ほかのウィンドウに切り替えると（Alt+Tab など）、ゲームは自動で一時停止します。

### ゲームパッドが反応しない
- つないだあとに、どれか1つボタンを押してください。
- うまくいかない場合は、USB ケーブルでつなぐのが確実です。

### 設定が保存されない
- ブラウザの「シークレット / InPrivate」ウィンドウでは設定が保存されません。ふつうのウィンドウで開いてください。
