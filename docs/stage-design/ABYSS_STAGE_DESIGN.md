## 1. スプラッターハウスから抽出する設計原則

| # | 原作で見られる特徴 | 抽出した原則 | 本設計での使い方 |
|---|---|---|---|
| 1 | 強制的に右へ進む横スクロール。戻れない | **一方通行を物語にする** | 背後の道が崩れて闇に消える演出。「戻れない」を画面で見せる |
| 2 | 地下牢 → 屋敷の中 → 異界へと、舞台が現実から離れていく | **現実度を段階的に下げる** | 石 → 屋敷 → 肉 → 反転 → 胎内。前半ほど「知っている場所」にする |
| 3 | 家具が襲ってくる部屋（ポルターガイスト）、鏡の中の自分 | **日常の物を敵にする** | 肖像画の目、飛ぶ椅子、自分の顔の肖像画 |

| 5 | 各ステージ末に閉じた部屋でボス戦 | **緊張のピークでは空間を閉じる** | カメラと出口をロックする「閉じた部屋」 |
| 6 | 倒した敵が壁に叩きつけられて飛び散る | **暴力の痕跡を背景に残す** | 返り血を壁のデカールとして残す。自分が通った道が汚れていく |
| 7 | ステージクリアで体力が少し戻る | **小さな報酬で次へ背中を押す** | 層の区切りでの回復・チェックポイント |

## 2. コア設計：「深度 D」ひとつで全てを動かす

ステージの進み具合を **深度 D（0.0 → 1.0）** という1本の数値で表し、
背景・光・霧・音楽・敵・揺れを**すべてDから計算**します。

```
プレイヤーのX座標 ──► 深度 D ──┬─► 背景マテリアル（石 → 肉）
                               ├─► ポストプロセス（彩度↓ 周辺減光↑ ノイズ↑）
                               ├─► 霧の濃さと色
                               ├─► BGMの各パート音量・音程のずれ・心音の速さ
                               ├─► 画面の揺れ、壁の脈動
                               └─► 敵の出現密度
```

こうすると「場所ごとに作り込む」のではなく「**数値を少しずつ上げるだけ**」で、
進むほど世界が壊れていく感覚が自然に出ます。AIに作業を頼むときも指示が単純になります。

さらに重要なのが **境界のにじみ**：各層の最後の約500ユニットで、次の層の色・音が**先に混ざり始める**。
遠景は実際より先の場所を映すので、次の層の景色が**画面の右から先に見えてくる**。
これが「見たい」の燃料になります。

## 3. 感情曲線（テンションの設計図）

「怖さ」と「知りたさ」を別々に設計し、両方を右肩上がりにしつつ、**意図的に谷を作る**のがポイントです。

| 層 | 名前 | 怖さ | 知りたさ | 狙い |
|---|---|---|---|---|
| 〇 | 雨の館 | ▁ | ▃ | 平穏。館にひとつだけ灯り。操作を覚える |
| 一 | 地下牢 | ▃ | ▃ | 最初の敵。「行くな」と刻まれた壁 |
| 二 | 歪む廊下 | ▄ | ▅ | 日常の物が敵になる。自分の顔の肖像画 |
| 三 | 分かれ道 | ▄ | ▇ | 上＝最後の月／下＝落下。選択が好奇心を試す |
| 四 | 肉の侵食 | ▆ | ▆ | 石が肉に変わる。壁が脈打つ |
| 五 | 彼女 | ▂→█ | █ | **安全地帯（谷）→ 最大の悲劇（山）** |

## 4. 層ごとの設計

各層は「舞台」「見せるもの（見たい）」「怖がらせるもの（進みたくない）」「音」「仕掛け」で設計します。

### 第〇層 雨の館（D 0.00–0.12）
- **舞台**：雨の夜、館の外。青灰色。遠景に館のシルエット。
- **見たい**：館の窓にひとつだけ灯り。そこに向かって歩く。
- **怖い**：まだ何も起きない。ときどき雷光で一瞬だけ景色が白くなる。
- **音**：雨音と雷だけ。**BGMは流さない**（後でBGMが「始まる」こと自体を演出にするため）。
- **仕掛け**：敵なし。操作説明はメモ（床の紙）で行う。

### 第一層 地下牢（D 0.12–0.25）
- **舞台**：石壁、鎖、揺れる松明。暖色だが暗い。
- **見たい**：床のメモ「地下へは行くな」。行くなと言われると見たくなる。
- **怖い**：最初の敵（亡者）。遅いが数が多い。倒すと壁に血が残る。
- **音**：低いドローン（持続音）と、ゆっくりした心音（約52 BPM）が**ここで初めて鳴る**。
- **仕掛け**：鎖が内側から引きちぎられている（何かが出て行った、という予告）。

### 第二層 歪む廊下（D 0.25–0.37）
- **舞台**：屋敷の廊下。壁紙、肖像画。紫がかった色。
- **見たい**：肖像画の目がプレイヤーを追う。一枚だけ新しい肖像画があり、それは**自分の顔**。
- **怖い**：椅子が浮いて襲ってくる（原作のポルターガイストへのオマージュ）。
- **音**：オルゴールの旋律が入る。最初は正しい音程で、わずかに揺らぎ始める。
- **仕掛け**：UE5版では「同じ廊下が繰り返され、少しずつ変わる」ループ構造も有効（1周ごとに肖像画が増える等）。

### 第三層 分かれ道（D 0.37–0.50）
- **舞台**：井戸のある空間。冷たい青黒。
- **分岐**：
  - **上（↑を押す）**：月の見える回廊。「これが最後の月かもしれない」。安全だが、**失った日常を最後に見せる**ことで後半の喪失感を強める。
  - **下（そのまま進む）**：床が抜けて落下。敵が増えるが、先の暗闇で何かが光っている。
- **狙い**：どちらを選んでも「先を見たい」理由が残るようにする。エンディングの文章が分岐で変わる。
- **音**：旋律の音程がずれ始め、不協和音（短2度のぶつかり）がかすかに入る。

### 第四層 肉の侵食（D 0.50–0.62）
- **舞台**：石が**少しずつ肉に置き換わる**。壁が脈打ち、血管が這う。壁に目が開く。
- **見たい**：血の跡が奥へ続いている（引きずられた跡）。誰が、どこへ？
- **怖い**：小さく速い敵（這う蟲）。視界がさらに狭まる。
- **音**：旋律は大きく崩れ、不協和音が前に出る。心音が速くなる（約78 BPM）。
- **仕掛け**：床が「あたたかい」というメモ。触覚的な言葉で気持ち悪さを出す。

### 第五層 彼女（D 0.62–0.75）★ 最重要
- **前半・安全地帯**：敵がいない。ろうそくの灯り。**オルゴールが正しい音程に戻り、ゆっくり鳴る**。心音も落ち着く。
  プレイヤーは一瞬ほっとする。ここが感情曲線の谷。
- **後半・悲劇**：探していた「彼女」が現れる。「来てくれたのね」—— 声が途中から別の何かに変わる。
  カメラと出口がロックされ、戦うしかない。体力が減るほど姿が崩れ、触手が伸びる。
- **音**：戦闘開始と同時にオルゴールがほぼ消え、不協和音が一気に満ちる。
  倒すと「オルゴールが止まった。進むしかない」。
- **狙い**：原作の最も有名な場面（恋人の異形化）の**構造**だけを借りる。
  守りたいものと戦わされる。ここで「進みたくない」が最大になり、同時に「なぜこうなったのか知りたい」も最大になる。

### 第六層 逆さ聖堂（D 0.75–0.87）
- **舞台**：逆さに吊られた十字架の並ぶ聖堂。紫と黒。
- **見たい**：祈りの言葉が逆から聞こえる。意味が分かりそうで分からない。
- **怖い**：ときどき画面が一瞬**色反転**する。ささやき声が強くなる。
- **音**：オルゴールの旋律が**逆再生**される（第二層・第五層で聞いたメロディなので、逆になると気づく）。
- **仕掛け**：UE5版では、上下反転した部屋（天井を歩く）を短く挟むと効果的。

### 第七層 胎内（D 0.87–1.00）
- **舞台**：完全に有機的な空間。赤。肋骨のような弧が鼓動に合わせて膨らむ。
- **見たい**：「この鼓動の主に会えば、全部わかる」。
- **怖い**：視界は最小。画面全体が鼓動に合わせて赤く脈打つ。
- **音**：旋律は消え、**心音がBGMそのもの**になる（約120 BPM）。プレイヤー自身の鼓動と区別がつかなくなる。
- **最終戦**：巨大な心臓。目が開き、蟲を産み続ける。体力が減るほど産む間隔が短くなる。

### 終幕 夜明け
- 白い光に包まれ、館が崩れ落ちる。
- 分岐に応じた一文 +「それでも、あの底をもう一度覗きたいと思っている。」で締める。
  → 周回プレイ（もう一方のルート）への動機づけ。

## 5. 「進みたくないが、見たい」を生む10の技法

| # | 技法 | 具体的なやり方 | 効く感情 |
|---|---|---|---|
| 1 | **先の景色を先に見せる** | 遠景は実際より先の場所を映す。次の層の色が画面右からにじむ | 見たい |
| 2 | **先の音を先に聞かせる** | 次の層の音を右スピーカー側から先に鳴らす | 見たい／怖い |
| 3 | **光を前方だけに絞る** | 深度とともに視界の円が縮み、進行方向だけわずかに明るい | 進むしかない |
| 4 | **戻れないことを見せる** | 背後の道が崩れて闇に消える。カメラは前にしか進まない | 覚悟 |
| 5 | **予告してから見せる** | 「行くな」と書いたメモ、引きちぎられた鎖、引きずられた血の跡 | 見たい |
| 6 | **静寂を武器にする** | 冒頭はBGMなし。第五層前半は音を減らす。音が「始まる」「消える」こと自体が演出 | 緊張 |
| 7 | **慣れたものを壊す** | 同じオルゴール旋律を「正常 → ずれる → 戻る → 逆再生 → 消える」と使い回す | 不安 |
| 8 | **谷を作る** | 安全地帯の直後に最大の恐怖を置く | 落差 |
| 9 | **痕跡を残す** | 返り血が壁に残る。自分の暴力の記録が背景になる | 罪悪感 |
| 10 | **選択に意味を持たせる** | 上＝失う日常を見る／下＝深淵を先に覗く。エンディングが変わる | 周回意欲 |

## 6. Unreal Engine 5 での作り方

### 6.1 仕組みの全体像（アセット構成）

| 役割 | UE5の機能 | 名前（例） | 何をするか |
|---|---|---|---|
| 深度の管理 | Blueprint（Actor） | `BP_DepthManager` | プレイヤーのX座標から D を計算し、下の全員に配る |
| 共有パラメータ | Material Parameter Collection | `MPC_Abyss` | `Depth`, `Pulse`, `ZoneBlend` をマテリアル全体で共有 |
| 壁・床の変化 | マテリアル | `M_AbyssWall` | 石テクスチャと肉テクスチャを `Depth` とノイズで混ぜる。World Position Offset で脈動 |
| 画面の雰囲気 | Post Process Volume（範囲無限） | `PPV_Abyss` | 彩度、周辺減光（Vignette）、フィルムグレイン、色収差を D で変化 |
| 霧 | Exponential Height Fog | — | 濃さと色を D で変化 |
| BGM | MetaSound Source | `MS_AbyssBGM` | 入力 `Depth`(float) で各パートの音量・音程のずれ・心音の速さを変える |
| 拍の同期 | Quartz | — | 心音と画面の脈動（`MPC_Abyss.Pulse`）を同じ拍で動かす |
| 残響 | Submix / Reverb | — | 深くなるほど残響を長く |
| 一方通行 | Blueprint | `BP_OneWayWall` | カメラ左端に見えない壁。背後に崩落エフェクト |
| 閉じた部屋 | Blueprint + Trigger Box | `BP_ArenaLock` | 入るとカメラ固定＋左右を封鎖、ボス撃破で解除 |
| 分岐 | Level Streaming / Data Layer | `LV_Z3_Upper` / `LV_Z3_Lower` | 選んだ側だけ読み込む |

### 6.3 Claude Code に貼る指示文（上から順に1つずつ）

1回に1つだけ頼み、そのたびにエディタで再生して確認してください。

**① 深度の仕組み**
```
BP_DepthManager を作ってください。レベルに1つ置くActorです。
プレイヤーのX座標を、ステージ開始点(StartX)と終点(EndX)の間で 0〜1 に換算して Depth という変数に入れ、
毎フレーム Material Parameter Collection「MPC_Abyss」の Depth に書き込んでください。
デバッグ用に画面左上へ Depth の値を表示してください。
```

**② 層のデータ表**
```
Data Table「DT_AbyssZones」を作ってください。行は8層（Z0〜Z7）、列は
Light, Rain, Drone, Heart, BPM, MusicBox, Detune, Dissonance, Whisper, FogDensity, FogColor, Saturation, VignetteIntensity。
値は docs/stage-design/ABYSS_STAGE_DESIGN.md の 6.2 の表を使ってください（Fog/Saturation/Vignette は Light から逆算した仮の値で構いません）。
BP_DepthManager は現在の層と次の層を、層の最後の約500ユニットで補間した値を毎フレーム計算してください。
```

**③ 画面の雰囲気**
```
範囲無限の Post Process Volume「PPV_Abyss」と Exponential Height Fog をレベルに置き、
BP_DepthManager が補間した値で、彩度・Vignette・Film Grain・色収差・霧の濃さと色を毎フレーム更新してください。
```

**④ 石から肉へ変わる壁**
```
マテリアル「M_AbyssWall」を作ってください。石のテクスチャと肉のテクスチャを、
MPC_Abyss の Depth とワールド座標のノイズでブレンドします（Depth 0.45 から肉が混ざり始め、0.8 で完全に肉）。
Depth が 0.5 を超えたら World Position Offset で壁がゆっくり脈打つようにし、
脈の速さは MPC_Abyss の Pulse に合わせてください。
```

**⑤ 深度で壊れていくBGM**
```
MetaSound Source「MS_AbyssBGM」を作ってください。float入力は Depth と各パートの音量（Rain, Drone, Heart, MusicBox, Dissonance, Whisper）、BPM、Detune、Reverse(bool)。
・Drone：低いのこぎり波2本＋ローパス。Detune が大きいほど2本の音程をずらす
・Heart：BPM に合わせて「ドクン、ドクン」の2打。Quartz で拍を刻み、拍ごとに MPC_Abyss.Pulse を 1→0 に落とす
・MusicBox：オルゴールの旋律（Aマイナー、16音）。Detune(cent) だけ毎音ランダムに音程をずらす。Reverse が true なら逆順
・Dissonance：短2度でぶつかるサイン波の塊
BP_DepthManager から毎フレーム値を渡してください。
```

**⑥ 一方通行と背後の崩落**
```
横スクロール用のカメラを作り、カメラは右にしか進まないようにしてください。
カメラ左端のすぐ内側に見えない壁（BP_OneWayWall）を追従させ、プレイヤーが戻れないようにしてください。
左端には崩れ落ちる瓦礫の Niagara エフェクトと、黒いグラデーションを重ねてください。
```

**⑦ 閉じた部屋（ボス戦）**
```
BP_ArenaLock を作ってください。Trigger Box に入ると、カメラをその場で固定し、左右に見えない壁を出してプレイヤーを閉じ込めます。
指定したボスが倒れたら壁とカメラ固定を解除します。第五層「彼女」と第七層「心臓」に使います。
```

**⑧ 分岐**
```
第三層の分かれ道を作ってください。分岐点の手前で「↑で上の回廊へ」と表示し、
```

### 6.4 作る順番（おすすめ）

1. まず**灰色の箱だけ**で第〇〜七層を一直線に並べ、①〜③と⑥だけ入れて歩いてみる（「暗くなっていく」だけで効果が分かる）
2. ⑤のBGMを入れる（**音だけで恐怖の半分が決まります**）
3. ④の壁マテリアル、⑦のボス部屋
4. 第五層「彼女」を作り込む（最重要）
5. ⑧の分岐、メモ、返り血などの細部

アセット（石・肉のテクスチャ、亡者のモデルなど）は自作せず、Fab の既製品で揃えるのが早道です。

## 7. 完成度チェック（遊んで確かめること）

- [ ] 第〇層で「館の灯り」に向かって**自分から**右へ歩きたくなるか
- [ ] 層が変わる前に、次の層の色や音に**気づけるか**
