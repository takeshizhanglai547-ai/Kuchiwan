ホーム画面に追加

これはストア登録不要のPWAです。公開HTTPS上のアプリをブラウザで開いてから追加します。ゲームのプレイ中なら、先にタイトルへ戻ってください。

iPhone・iPad

  1. Safariでこのアプリを開きます。
  2. 共有ボタンを押し、必要なら「さらに表示」から「ホーム画面に追加」を選びます。
  3. 「Webアプリとして開く」が表示されたらオンにし、「追加」を押します。
  4. ホーム画面のイッヌのアイコンから起動します。

Apple公式：iPhone · Apple公式：iPad

Android

  1. Chromeでこのアプリを開きます。
  2. メニューから「インストールとショートカットを作成」→「インストール」を選びます。表示名は端末やChromeの版によって異なる場合があります。
  3. アプリ内に「ホーム画面に追加」ボタンが出ていれば、そのボタンも使えます。

Google公式：Webアプリの利用

オフラインと更新

初回はネットにつないで「保存済み」と表示されるまで待ってください。更新通知が出たら、アプリメニューで更新します。更新ではプレイを終了してタイトルから読み直します。操作中に勝手に再読込することはありません。

オフライン時は保存した版を表示します。ブラウザが保存を削除した場合はオンラインで開き直してください。端末のWebGL対応、実際のインストールとオフライン起動には実機確認が必要です。
