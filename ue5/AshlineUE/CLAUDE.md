## 1. 世界観（すべて本作の独自設定）

> **重要**：ASHLINE の世界設定・用語・意匠は、すべて本作固有のものです。
> 既存作品の固有名詞・記章・キャラクター意匠を持ち込むことを禁じます
> （詳細は §6）。以下の語はこのプロジェクトのために作られたものです。

### 前提

数十年前、空にあった巨大な構造物が落ちた。
落下点を中心に、灰が帯状に降り積もった土地ができた。
その帯を人は **灰線（かいせん / ASHLINE）** と呼んでいる。

灰は季節ごとに動く。だから灰線の位置は、毎年引き直さなければならない。
それをやるのが **測線員（そくせんいん）** ——
測量道具と銃を持って灰線を歩き、標を打ち直す仕事の人間である。

銃が要る理由は単純で、**落ちた構造物がまだ動いているから**。

### 敵 —— 残響体（ざんきょうたい）

構造物が地表に散らした自動機械の残り。
四十年前に受け取った最後の指示を、いまも実行し続けている。
彼らは敵意を持っていない。手順を持っているだけで、
その手順の中に「区画内の移動物を排除する」という一行が残っている。

| 種別 | 名称 | 役目（コア側の `EnemyType` と対応） |
|---|---|---|
| rusher | **走査体（そうさたい）** | 区画を巡回する。近づいて確認しようとする |
| marksman | **測距体（そっきょたい）** | 遠くから測り、測り終えると撃つ |
| heavy | **積層体（せきそうたい）** | 灰を纏って厚くなった個体。正面からは削り切れない |

### 舞台 —— 第7測点

本作で遊べる区画。40m × 40m のコンクリートの測量場で、
測線員が標や資材を置くために積んだ箱が散らばっている。
その箱が、そのまま遮蔽になる。

**ここが本作の要**：遮蔽は「戦うために置かれた壁」ではなく、
**仕事のために積まれた荷物**である。だから配置は戦術的に整っておらず、
高い箱と低い箱が混ざり、都合の良い場所には無いことがある。
プレイヤーは与えられた地形ではなく、他人の仕事の跡を使って戦う。

### トーン

- 敵に憎悪を向けない。**片付ける**という感触にする
- 勝利は制圧であって殲滅ではない。バナーの文言もその線で書く
- 色は灰と、標識の色（測量の朱・退避の黄）だけで足りる

## 2. 5本の柱

この 5 つのどれかを壊す変更は、それがどれだけ「面白そう」でも入れない。

### 柱1 — 止まって撃つ

移動しながら撃っても当たらない。止まると当たる。
これはペナルティではなく、**「どこで止まるか」を毎秒の判断にするための仕掛け**。
実装上は、移動中の集弾の減衰（`fire::spreadMove`）と、
状態依存のエイムアシスト（`Sim::AssistScale`）が支えている。
**この条件は敵にも同じように課している**（敵は撃つ前に必ず止まる）。
プレイヤーだけが不利になる仕組みにしないこと。

### 柱2 — 遮蔽が本当に弾を止める

見えている壁は、必ず弾を止める。逆に、見えていない壁は止めない。
`AshlineWorld` のレイ判定が唯一の正であり、
**レベルに置いた見た目のメッシュがそこから 1cm でもずれてはいけない**。
（そのために `AAshlineGameMode::GetCoverBoxes()` がある。手で並べないこと。）

### 柱3 — 正面が塞がったら、位置を変える

積層体は正面から削り切れない体力を持つ。
だから「もっと撃つ」ではなく「別の面から撃つ」が答えになる。
遮蔽から遮蔽への乗り換え（Swap）と乗り越え（Vault）は、
その答えを実行するための移動手段として存在する。

### 柱4 — ボタン1つが、状況によって別の意味になる

遮蔽に入る・ダッシュする・乗り換える・乗り越える —— すべて同じボタン。
何が起きるかは、そのときの状態と入力方向でコアが決める
（`Input::action` / `Input::actionEdge`）。
プレイヤーが覚えるのは「押す」ことだけで、
**覚える量ではなく、状況を読む量で難度を作る**。

> 補足：柱1・柱2・柱3・柱5 は既存のコード内コメント（`game.js` / `AshlineWorld.h`）
> に出てくる呼び方をそのまま使っています。柱4 はコメント中に明示的な記述が
> 無かったため、実装（文脈依存アクションとアクティブリロード）から
> ここで言語化したものです。正典の定義が別にある場合はそちらを優先してください。

### 柱5 — 画面の外が分かる

敵の位置が、画面を見なくても音で分かること。
HUD で矢印を出して解決しない。音と、被弾方向のカメラの振れで伝える。

## 3. 技術方針

### 3-1. ルールはコアが持つ。UE5層は表示しかしない

```
AshlineCore （UE非依存 / メートル / Y-up）      ← 判断はすべてここ
    ↑ Ashline::Input を渡す / 結果を読むだけ
AshlineUE   （UE依存 / cm / Z-up）             ← 見せ方だけ
    ↑ 見た目・音・演出
Blueprint
```

**なぜこうするのか**：UE5 が入っていない環境でもルールを実行でき、
Web 版と同じ問いを投げて答えの一致を数値で確認できるから
（`ue5/tests/run.sh`）。「エディタで再生してみた感じ」ではなく数値で
正しさを確かめられる状態を、最後まで維持する。

判断を UE5 層に 1 つ書くたびに、検証できない部分が 1 つ増える。
`AAshlinePlayerPawn` に `if` を書きたくなったら、それは
`AshlineCore` に書くべき `if` である。

### 3-2. C++ とブループリントの分担

| | 担当 |
|---|---|
| **C++** | ルール（コア）、Sim の呼び出し、座標変換、Blueprint へ渡す数値の用意 |
| **Blueprint** | 見た目、音、Niagara、UI のレイアウト、アセットの割り当て、レベル構成 |

見た目は作り直す回数が一番多い。そこを C++ に置くと、
試行錯誤のたびに 10 分のビルドを待つことになる。
だから C++ は「数値を置く」「起きたことを `BlueprintImplementableEvent` で伝える」
までにして、そこから先はエディタの中だけで完結させる。

### 3-3. 単位と座標系

- コア：**メートル / Y-up / three-style yaw**（`yaw y` → 前 = `(-sin y, 0, -cos y)`）
- Unreal：**センチメートル / Z-up / 左手系 / Yaw は度**
- 変換は **`AshlineBridge.h` だけ**が行う。導出のコメントが同ファイルにある。
  符号が合わないときは、その導出に戻ること。**勘で反転させないこと。**

### 3-4. Tick の順序

`AAshlinePlayerPawn`（`TG_PrePhysics`）が `Sim::Step()` を 1 回だけ呼び、
`AAshlineEnemyActor`（`TG_PostPhysics`）と HUD がその結果を読む。
この順序が逆になると、画面に出る敵の位置が常に 1 フレーム古くなる。

### 3-5. 衝突

**UE の物理・衝突は使っていない。** カプセルも敵もコリジョンは切ってある。
当たり判定は `AshlineWorld`（円 vs AABB とレイ）が唯一の正。
UE 側で衝突を有効にすると、2 つの物理が同じ物体を押し合って必ず破綻する。

## 6. やってはいけないこと

### 6-1. 設計を壊す行為

1. **`AshlineConfig.generated.h` を手で編集する**
   自動生成物です。`ue5/tests/run.sh` の手順1が真っ先に失敗します。
   数値を変えたいときは `ashline/game.js` を直して
   `node ue5/tools/gen_config.js` を実行してください。

2. **Actor にゲームの判断を書く**
   「遮蔽に入れるか」「撃てるか」「ダッシュできるか」は全部コアの仕事です。
   表示層に書いた判断は、UE5 が無い環境で検証できません。

3. **`AshlineCore` の中に cm / Z-up / UE の型を持ち込む**
   `FVector` も `TArray` もコアには入れないこと。
   入れた瞬間に、UE 非依存であることで得ていた検証手段が丸ごと失われます。

4. **`AshlineBridge` を通さずに `* 100` や符号反転を手書きする**
   変換が散らばると、原因の場所と症状の場所が離れて追えなくなります。

5. **見た目のメッシュを手で並べる**
   遮蔽は `GetCoverBoxes()` から座標を受け取って配置すること。
   見た目と当たり判定のズレは、このリポジトリで過去に実際に起きています。

6. **UE の物理・キャラクタームーブメントを有効にする**
   コアの移動と押し合って必ず震えます。

### 6-2. 知的財産に関する厳格な禁止

ASHLINE は「遮蔽に入って撃ち合う**遊びの手触り**」だけを参照しています。
既存作品からの以下の持ち込みを、いかなる形でも禁止します。

- 既存作品の**固有名詞**（武器名・組織名・地名・キャラクター名）
- **記章・紋章・ロゴ**の引用または模倣
- 既存キャラクターの**シルエット・意匠**に寄せた造形
- 既存作品の**アセットそのもの**（モデル・テクスチャ・音）の使用

世界設定の語彙が必要になったら、**新しく作ってください**。
§1 の語（灰線 / 測線員 / 残響体 / 走査体 / 測距体 / 積層体 / 第7測点）は
すべてそのために作られたものです。同じやり方で増やせます。
