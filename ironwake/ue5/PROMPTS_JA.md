# Claude Code にコピペで渡す指示文集（IRONWAKE を Unreal で作り直す）

> **⚠ 未検証（UNVERIFIED IN UNREAL ENGINE）**: この指示文は、Unreal Engine の無い環境でウェブ版をもとに書きました。
> 指示どおりに Claude Code が作っても、そのまま完璧に動くとは限りません。各ステップの「確認」で遊んでみて、
> おかしければ「◯◯が△△になる。直して」と伝えてください。

## 使い方

1. 先に `README_JA.md` の手順 1〜8 を終わらせておきます（プロジェクト作成・モデル読み込み・Claude Code とプラグインの接続）。
2. 下のステップを **上から順に、1回に1つずつ** Claude Code に貼り付けます（灰色の枠の中をまるごとコピー）。
3. Claude Code が終わったら、エディタで **▶ プレイ（Alt+P）** して「確認」の項目を試します。
4. よければ **「ここまでを git でコミットして」** と頼んでから次へ。ダメなら直してもらってから次へ。
5. 数値の出どころはすべて `ue5/GAME_SPEC.md`、ルールは `CLAUDE.md` です（毎回書かなくても Claude Code が読みます）。

## ステップ 2: 地上ブースト（高速走行）と止まり方

```

## ステップ 4: クイックブースト（このゲームの主役）

```
クイックブースト（QB）を作ってください（GAME_SPEC.md §2）。
- Shift / パッド B を押した瞬間に1回（押しっぱなしで連発しない）
- 方向: 移動入力の方向（入力なしなら前）。速度を一瞬で max(105 m/s, 今の速さ + 30 m/s) に設定
- 0.35 秒その速さを保ち、その後は時定数 0.12 秒で通常の移動速度へ戻る。地上で入力なしなら踏ん張って止まる
- EN 17 消費、クールダウン 0.55 秒、噴射中の重力は 0.1 倍（空中 QB は少し浮く）
- 見た目と手ごたえ: カメラの FOV を一瞬 +5°（0.06 秒保持→0.45 秒で戻す）、ブーストと逆方向へカメラを 0.4 m キック、
  小さなカメラシェイク。噴射方向に仮のエフェクト（Niagara のバースト）と「ドンッ」という効果音（仮で可）
```
**確認:** 横に Shift を押すと約 40 m 一瞬で跳ぶ。6回くらい連続で使うと EN が尽きて赤くなり、2秒使えなくなる。

## ステップ 6: アサルトブースト（高速巡航）

```

## ステップ 9: ダメージと姿勢（STAGGER）

```

```

- ブレード: 42 m まで詰めてから腕を引く予兆 0.55 秒 → 最大 70 m 突進して斬る（ダメージ 1400）。重み 2.2、クールダウン 5 秒
