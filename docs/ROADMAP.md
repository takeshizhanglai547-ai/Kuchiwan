# 開発ロードマップ — 聖犬士イッヌ

「エルデンリング並の大作」は最終目標。そこへは**小さく動くものを積み上げて**到達します。
各マイルストーンは「前のものが遊べる状態」を壊さずに足していきます。

## ✅ M0: 操作できる主人公（今ここ / このコミットで土台完成）
- 三人称カメラ、移動・ジャンプ・ダッシュ
- 回避ロール（無敵時間・クールタイム・スタミナ消費）
- 近接コンボ攻撃（モンタージュ連結）
- ロックオン（画面中央の敵を選び、カメラ追従）
- 体力・スタミナ管理（AttributeComponent）
- 調べる相互作用（IInteractable インターフェース）
- → 残りは Unreal Editor 上でメッシュ/入力/アニメを割り当て（docs/SETUP.md）

## M1: 戦える主人公
- 攻撃の当たり判定（武器ソケット間トレース or AnimNotify でヒット）
- ダメージ適用 → 敵の AttributeComponent へ
- ヒットリアクション、被弾無敵、死亡処理
- 簡単な敵キャラ（巡回 → 索敵 → 接近 → 攻撃 の BehaviorTree/AI）

## M2: 探索できる世界
- かがり火型セーブ／リスポーン（チェックポイント）
- 収集アイテム・宝箱（IInteractable 実装）
- 鍵と扉、ショートカット解放
- ミニマップ／方角ガイド
- 環境ギミック（壊せる壁、昇降、ロープ など）

## M3: 成長と装備
- 経験値・レベル・ステータス（HP/スタミナ/攻撃力）
- 装備（剣・鎧・マント = キャラ画稿の聖騎士装備を反映）
- 消費アイテム（回復、バフ）
- スキル／必殺技

## M4: ボスと世界観
- フェーズ制ボス戦
- ロックオン UI、ボス体力バー
- ステージ（城・森・遺跡 = 画稿の背景イメージ）
- 物語・NPC会話

## M5: 仕上げ
- セーブ/ロード（SaveGame）
- タイトル・設定・ポーズメニュー（UMG）
- サウンド・BGM、エフェクト磨き
- 最適化（Nanite/Lumen/LOD/カリング）、パッケージング

---

## 技術メモ
- **入力**: Enhanced Input
- **AI**: Behavior Tree + Blackboard + EQS
- **戦闘の拡張余地**: GameplayAbilitySystem(GAS) への移行を M3 で検討
  （ステータス・バフ・スキルが増えたら GAS が効いてくる）
- **アセット**: キャラはクワイ画稿の聖騎士イッヌ。Mesh/Anim/マップは
  エディタまたは外部DCC(Blender等)で用意してインポート
- **規模感の現実**: ソロ/小規模ではM2あたりまでで「縦の一本（バーティカルスライス）」を
  完成させ、面白さを確認してから世界を横に広げるのが定石
