# 1台の画面で2人協力

タイトル上部の「1台で2人協力」から、P1とP2のキャラクター・難易度を選びます。スマホ・iPadは横向きをおすすめします。これは同じ端末で同時に遊ぶモードです。別端末オンライン協力はまだ含みません。

左右にそれぞれ移動スティックと6ボタン（攻撃、ジャンプ、つかむ、よける、必殺、奥義）があります。方向＋攻撃の各コマンドも使えます。P1・P2それぞれの入力履歴、HP、奥義ストック、つかみ状態は独立しています。頭上のP1/P2表示と色を目印にしてください。

| 操作 | P1 | P2 |
|---|---|---|
| 移動・方向入力 | 矢印 | WASD |
| 攻撃 | J | F |
| ジャンプ | I / Space | R |
| よける | K | G |
| つかむ・解放 | L | T |
| 必殺 | H | Y |
| 奥義 | O | B |
| 一時停止 | P / Esc | 画面の II |

コマンドの向きは各キャラの向きが基準です。入力猶予や技の消費は `INPUT_CONTROLS.md` とゲーム内「技一覧」を参照してください。対応するゲームパッドが2つある場合は、パッド0がP1、パッド1がP2です。

敵・ボスHP・ステージ進行・残機は共有します。味方同士は攻撃しません。敵を2人で同時につかむことはできません。倒れたキャラは通常と同じ100Fの復活待ち後、共有残機を1つ使って復活します。残機がなくなればゲームオーバーです。ステージ達成と同時の死亡はクリアを優先します。

カメラは2人の中間を追い、画面から離れすぎないよう移動範囲を制限します。敵は近い生存プレイヤーを狙います。開始・クリア演出はP1、P2それぞれのキャラ固有イベントを順番に表示します。ボスの後半戦演出は共有の1回です。演出中は両者の操作を消去し、同じスキップボタンで進めます。ステージを進めると各キャラの状態を引き継ぎ、やり直しでは新しい2人を作成します。

## 検証

`node tests/25d/coop_cpu.cjs` は実際の2プレイヤー・ネイティブ技処理、共有HP、入力チャンネルと12ボタンのコールバック、つかみ排他、復活、全キャラの全7ステージ進行・演出、および336コマンド振り分け比較を実行します。`coop_mutations.cjs` は同時進行、入力分離、解放とつかみ所有権を壊した変種が失敗することを確認します。

これらはCPU・DOM試験用環境での検証です。ブラウザの実際の配置・描画、スマホ/iPadの信頼されたマルチタッチ、実際の遊びやすさの確認は別途必要です。別端末の通信試験を実施した結果ではありません。
