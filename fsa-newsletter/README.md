# 金融庁ニュースレター自動生成システム

金融庁ウェブサイトの最新報告書・発表資料を自動取得し、Claude AI（Opus 4.6）が大手法律事務所スタイルのニュースレターを生成するシステムです。

## 機能

- **自動情報収集**: 金融庁ウェブサイトから最新の報告書・監督指針・行政処分・パブリックコメントを自動取得
- **AI法的分析**: Claude Opus 4.6（Adaptive Thinking）が深い法的分析と実務上の示唆を提供
- **プロ品質の文書**: 大手法律事務所（西村あさひ、森・濱田松本、アンダーソン・毛利・友常スタイル）のニュースレターをリアルタイム生成
- **ストリーミング表示**: Server-Sent Eventsでニュースレターをリアルタイムで表示
- **デモモード**: APIキーなしでもデモ動作を確認可能

## セットアップ

### 1. 依存パッケージのインストール

```bash
cd fsa-newsletter
npm install
```

### 2. APIキーの設定

```bash
export ANTHROPIC_API_KEY=your-api-key-here
```

または `.env` ファイルを作成:

```bash
cp .env.example .env
# .env を編集してAPIキーを設定
```

### 3. サーバー起動

```bash
npm start
```

ブラウザで `http://localhost:3000` を開いてください。

## 使い方

1. **「取得 → 生成（一括実行）」** ボタンをクリック
2. 金融庁サイトから最新情報を自動取得
3. Claude AIがリアルタイムでニュースレターを執筆
4. 完成したニュースレターをコピー・印刷

### デモモード

APIキーなしでも動作確認できます：
- サイドバーの「デモモード」トグルをONにする
- または ANTHROPIC_API_KEY を設定せずに起動

## 技術スタック

- **Backend**: Node.js + Express
- **AI**: Anthropic Claude Opus 4.6（Adaptive Thinking）
- **Web Scraping**: Cheerio + node-fetch
- **Streaming**: Server-Sent Events (SSE)
- **Frontend**: Vanilla HTML/CSS/JS（フレームワーク不要）

## ニュースレターの構成

各ニュースレターには以下が含まれます：

1. **巻頭言**: 今月の金融規制動向の総括
2. **各トピックスの解説**:
   - 概要
   - 法的・規制上の意義
   - 実務上の留意点・対応策
   - 今後の見通し
3. **まとめ・総評**
4. **免責事項**

## 対応する金融庁情報カテゴリ

| カテゴリ | 内容 |
|---------|------|
| 報告書・調査結果 | 各種調査・研究報告書 |
| 監督指針・ガイドライン | 金融機関向け監督方針 |
| 行政処分 | 業務改善命令・業務停止命令 |
| パブリックコメント | 規制改正に関する意見募集 |
| 規制改正 | 府令・規則・告示の改正 |
| 注意喚起 | 投資家等への注意喚起 |
