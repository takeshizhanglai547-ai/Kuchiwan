# 元の2.5D版を配るPWA互換パッケージ

ゲーム内容は `040cf980ef39488c470cbc6a73ea47652007fa12` です。通常の `beltaction25d.html`、全15ゲームモジュール、`inu25d/shell.html` は同コミットと一致します。511を親にする新しい復元コミットであり、公開履歴は書き換えません。未公開の移動修正6c7、別端末オンライン527は含みません。

既存の `inu25d/app/`、`game.html?app=1`、manifest、icons、service workerのURLを維持します。PWAゲーム本体は元の通常HTMLと同じゲームで、Three.js埋め込み、外部フォント参照の除去、アプリ保存/更新UIだけが違います。追加コマンド・つかみ操作・同画面2人・追加ボス演出/キャライベントのモジュールは含みません。App Store版ではありません。

## 更新と保存

配信ハッシュから新しいキャッシュ番号を生成します。インストール時に全10アセットをSHA256検証し、完全な保存ができた後だけ切り替え可能です。新しい本体でタイトル/アプリ入口にいるときは待機ワーカーの切り替えを進めます。戦闘中には強制再読込しません。起動済みの古い追加版本体には更新通知が表示され、プレイを終えて「アプリ」→「更新を確認」から更新できます。全アプリ画面を閉じて再起動する方法もあります。

有効化時に、このアプリの同じscopeに属する旧キャッシュだけを削除します。他ゲーム・別scopeのキャッシュは保持します。ゲームの `inu25d_save` を削除・移行・上書きしません。オフラインのままの端末には新しい内容を送れないため、一度オンラインで開く必要があります。旧版固有のセーブ解釈も元のコードへ戻ります。

## 再現コマンド

```
node tools/build25d-pwa.cjs
node tests/25d/rollback_cpu.cjs
node tests/25d/pwa_cpu.cjs
node tests/25d/pwa_ui_cpu.cjs
node tests/25d/pwa_build_variant.cjs
node tests/25d/rollback_mutations.cjs
```

通常HTMLは元版との完全一致を保つため再生成せず、PWAを再生成します。従前の追加版向け全21スイートは削除した追加機能を前提とするため、この復元版の合格判定には使用しません。

復元4グループ（42移動入力、7キャラ攻撃/ジャンプ、セーブ読み取り、元ソース/HTMLハッシュ）、PWAキャッシュ17グループ、元ゲームと組み合わせたアプリUI9グループ、別ビルド2ケース、4変異で検証します。すべてCPU/合成DOMまたは静的検証です。iPad実機・信頼されたブラウザータッチ・WebGL描画・実サービスワーカーの受入確認ではありません。公開反映は別途手動pushと同SHAのPages/公開ハッシュ確認が必要です。
