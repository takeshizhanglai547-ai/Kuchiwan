## 元からあったものと今回の変更

- 元から：前／上／下／下上／波動／昇竜の原作コマンド、地上／空中の別技、独立したつかむボタン、無方向／上／下／後ろの各キャラのつかみ技。
- 不足していた配線：タッチは4ボタンで、必殺・奥義の内部アクションは専用ボタンやキーへ接続されていませんでした。昇竜の最後を斜め下で止める動作も、原作の四方向履歴だけでは認識できませんでした。
- 今回：8方向履歴から斜めを含む入力を読み、**元の2D戦闘分岐**へ変換します。技・ダメージ・当たり・キャンセル・演出は元のキャラ別定義を使用します。必殺／奥義を別ボタンと別キーへ接続し、つかむを大きな手のアイコンにしました。
- つかみ状態の案内、つかみボタン再押しの解放、相手の死亡／除去時の解放も追加しました。

矢印左右が移動、上下は技の選択です。A/Dはメニュー操作には使えますが、この候補の戦闘移動キーではありません。

## 方向＋攻撃は専用ボタンと別

右向きの例。左向きでは前・後ろと斜めを反転します。

| 入力 | 動作／入力窓 |
|---|---|
| 前＋攻撃 | キャラ別の前技 |
| ↓＋攻撃 | キャラ別の下技 |
| ↑＋攻撃 | キャラ別の上技 |
| ↓↑＋攻撃 | 下から上30F以内、最後の上を保持して34F以内 |
| ↓↘→＋攻撃 | 下から前20F以内、開始から攻撃28F以内、最後の前から9F以内 |
| →↓↘＋攻撃 | 各区間20F以内、開始から攻撃40F以内、最後の斜めから9F以内 |
| 後ろ→前＋攻撃 | 18F以内、最後の前から10F以内 |

1Fは戦闘時計の1/60秒。ヒットストップやイベント中は入力時計も止まります。原作の省略入力 `↓→` と `→↓→` も残しています。長いコマンドを単純方向より優先し、重なる昇竜と波動では昇竜を優先します。8方向入力中の逆方向は、その斜めコマンドを無効にします。

使った履歴は消費し、押しっぱなしの攻撃で別の技を繰り返しません。通常の無方向攻撃、押し直しコンボ、長押し解放のため攻撃も残っています。ジャンプ中の方向コマンドは原作の空中技です。

専用必殺は原作の**地上攻撃＋つかむ**の専用技と同じです。ストックは使わず、540F（通常速度で約9秒）の待機時間があります。空中では使えません。奥義ボタンは原作の地上／空中奥義を使い、必要なストックがなければ案内だけを出し、通常攻撃へ化けません。押しっぱなしや他ボタンからの指の滑りで奥義を発動させません。

従来の「回転＋攻撃」、空中の「攻撃＋つかむ」も互換操作として維持しています。通常の波動／昇竜の入力ではこれらへ化けないよう、認識した斜めコマンドは対応する原作の履歴だけを渡します。

## つかみの方向分岐と意図的な追加

- 正面の近い地上の相手へ、つかむボタンを押します。状態と残り時間を画面に表示します。
- **無方向／上／下／後ろ＋攻撃**は元の2D版の技をそのまま使います。ウォッチは原作通り、この4種類すべてが盗み技です。
- **前＋攻撃**は今回追加した入力マッピングです。原作では無方向と同じ決め技でしたが、既存の `punchImpact` 小攻撃（基礎6ダメージ、9F、4F目で命中）を接続し、保持を続けます。7人それぞれの既存モーション部品で小攻撃を表します。ストックは使いません。
- つかむをもう一度押すと解放。何もしなくても180Fで解放。相手の死亡／除去でも保持をやめます。
- ボスも原作通り、つかめる状態なら対象です。無敵・登場・変身中、空中の相手は対象にできません。ボス全般をつかみ無効には変更していません。
